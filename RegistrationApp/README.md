# RegistrationApp

\# RegistrationApp



PROG5121 Programming 1A - Portfolio of Evidence, Part 2



Thulani Mgidi, ST10528249



A Java console application with a registration and login feature.

Message feature was added to original registration application.

Users register with a username, password and South African cell

phone number, each validated against set rules, and can then log in

with the details they registered.

LoginTest added to test application.



\## Running it

Open the project in Apache NetBeans and run RegistrationApp.



\## Testing

Unit tests are in the test folder. Run them with right-click the

project then Test (Alt+F6).
